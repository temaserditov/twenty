# Решения

- 2026-10-15: Twenty запускается отдельным приложением. Интеграция использует опубликованный REST API и metadata API; ядро не изменяется, чтобы получать обновления upstream.
- 2026-10-15: Для первого подключения выбраны отдельные сущности лидов, заказов и учеников. Стабильные ID защищают от дублей, а автоматическое объединение по контактным данным отключено до определения правил идентификации.
- 2026-10-15: Приёмник сохраняет событие до ответа 202, затем пишет в Twenty. Ошибка CRM не влияет на обработку платежа или выдачу доступа в LMS.
- 2026-10-15: Все локальные секреты создаются через hermes-secrets в Bitwarden Infra. На диске находятся только bws-ссылки.
- 2026-10-15: Production пока не включён. Публикация и подключение боевых источников требуют явной команды владельца по правилам платформы.
